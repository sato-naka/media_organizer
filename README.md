# MediaOrganizer
## 概要
特定のフォルダから特定のフォルダへ年月ごとにフォルダ分けして画像や動画を振り分けるための簡易スクリプトです

## セットアップ
- exiftool をダウンロードして exe ファイルと `exiftool_files` フォルダを同じフォルダに入れる
- その時 exe ファイルは `(-k)` の名前を外す
- 同フォルダ内に `Camera` フォルダを作成しその配下に仕分けしたい画像や動画を入れる

## 使い方
- dat ファイルを実行
- `output` フォルダが作成され振り分けた画像や動画が格納されている
- 画像や動画はコピーされ元ファイルは消えない
